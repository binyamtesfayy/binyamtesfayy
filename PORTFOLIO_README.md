## 💻 Running Locally

1. **Clone the repository:**
   ```bash
   git clone https://github.com/binyamtesfayy/binyamtesfayy.git
   cd binyamtesfayy
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start the development server:**
   ```bash
   npm run dev
   ```

4. **Open in browser:**
   Open [http://localhost:3000](http://localhost:3000) to view the site.

## 📦 Production Build
